# AGENTS.md

This repository keeps one agent guide: [`CLAUDE.md`](CLAUDE.md). It applies to every coding agent, including Codex.

Before you do any work, read `CLAUDE.md` in full and follow it. Where it says "Claude Code", read it as the agent you are.

Do not copy `CLAUDE.md` into this file. A copy goes stale when `CLAUDE.md` changes. To change an agent instruction, edit `CLAUDE.md` only.
